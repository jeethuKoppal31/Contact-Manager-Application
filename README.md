# Contact-Manager-Application
This project demonstrates the core CRUD (Create, Read, Update, Delete) operations along with validation checks. It is designed to be efficient, simple, and easy to use, making contact management seamless.


 **Features**

- **Add New Contact**  
  Fill in details like name, email, phone number, and address, then save to store the contact.

- **Update Contact**  
  Modify existing contact information and update instantly.

- **Delete Contact**  
  Remove contacts with a confirmation prompt to prevent accidental deletion.

- **Validation Against Duplicates**  
  Ensures no two contacts have the same email or phone number, keeping the contact list accurate and clean.

---

 **Technology Stack**
 • Backend: Python 3.8, Django 4.2
 • Database: SQLite
 • Frontend: HTML, CSS, Bootstrap


**Why This Stack?**
 • Django provides rapid development with built-in ORM and admin features.
 • SQLite is lightweight and ideal for quick development/testing.
 • Bootstrap ensures a responsive and user-friendly interface
